Temperature Converter Website

Project Overview

The Temperature Converter is a responsive web application developed as part of the Oasis Infobyte Internship (OIBSIP) Web Development and Designing track. It converts temperatures between Celsius, Fahrenheit, and Kelvin.

Technologies Used

- HTML5
- CSS3
- JavaScript

Features

- Convert temperatures between Celsius, Fahrenheit, and Kelvin.
- Display all three temperature units simultaneously.
- Validate user input.
- Show an error message for temperatures below absolute zero.
- Responsive and user-friendly design.
- Simple and clean interface.

How to Use

1. Open the website in a web browser.
2. Enter a temperature value.
3. Select the input unit: Celsius, Fahrenheit, or Kelvin.
4. Click the Convert Temperature button.
5. View the converted results in all three units.

Project Files

- "index.html" — Website structure.
- "style.css" — Website styling and responsive design.
- "scripts.js" — Temperature conversion logic and input validation.

How to Run

1. Download or clone the project folder.
2. Open "index.html" in your web browser.
3. Start converting temperatures.
