NovaTech Landing Page

Project Description

NovaTech is a modern, responsive landing page for a digital solutions company. It presents the company's services and encourages visitors to explore its offerings.

Features

- Navigation bar with Home, Services, About, and Contact links
- Hero section with a headline and call-to-action button
- Services and About sections
- Contact section and footer
- Modern dark-blue design
- Responsive layout for different screen sizes

Technologies Used

- HTML5
- CSS3

How to Run

1. Download or clone this project.
2. Open the project folder in Visual Studio Code.
3. Open "index.html" using a browser or the Live Server extension.
